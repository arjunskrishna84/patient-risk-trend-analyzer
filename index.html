Reading the direction of a patient's vitals, not just the numbers

An ML.NET web app that reduces irregular blood pressure, glucose, oxygen and weight readings to eight trend features, predicts disease risk, and explains the result in plain language.

How a prediction is made

One ASP.NET Core process. The model trains once at startup, one endpoint serves predictions, and a single HTML page is the interface. No database, no external services.

  1. Upload or load a sample. The page sends a JSON patient file to POST /api/predict.
  2. Validate. Needs a name, at least one tracked vital, at least 5 readings, and no null values for tracked vitals.
  3. Build features. Eight numbers: four averages, one weight change, three trends.
  4. Predict. ML.NET logistic regression returns a label, probability and score.
  5. Explain. Insight and recommendation engines produce the risk band, certainty, alerts, trend lines and next step.

Model and training data

The classifier is LbfgsLogisticRegression, trained at startup on 2,000 synthetic samples with an 80/20 split. Accuracy and AUC come back with every response.

What the audit found

Running the supplied test file through the code exposed these problems.

Zero is accepted as a measurementValidation only checks for null. Glucose and oxygen are 0 in all 13 readings, and one blood pressure reading is 0/0. An average SpO2 of 0 would show up as a critical alert.
No plausibility rangesA 365 kg weight passes. Its effect on WeightChange is hidden only because the first and last weights are both 0.
"Per day" trends are per readingThe code divides by the reading count, but the page labels the unit as per day. The 13 readings span 16 days.
Synthetic labelsPredictions reflect the thresholds written into the data generator rather than real clinical outcomes.

Recommended fix

Treat out-of-range values as missing, then compute averages and trends over valid readings only.

static float? Clean(float? v, float min, float max)
    => v is { } x && x >= min && x <= max ? x : null;

var systolic  = Clean(r.Systolic,  50, 260);  // mmHg
var diastolic = Clean(r.Diastolic, 30, 160);  // mmHg
var glucose   = Clean(r.Glucose,   20, 600);  // mg/dL
var oxygen    = Clean(r.Oxygen,    50, 100);  // SpO2 %
var weight    = Clean(r.WeightKg,   2, 350);  // kg

Next steps: divide trends by elapsed days, train on real longitudinal data, add cross-validation and trainer comparison, and derive explanations from model weights.

Run it locally

Requires the .NET 9 SDK.

dotnet --version
cd <folder containing the .csproj>
dotnet run

Open the URL printed in the console. Click Load sample data then Predict risk, or upload sample-patient-input.json.
